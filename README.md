# Мини-футбол 5×5 — геймплейный прототип (Unity)

Минимальное игровое ядро: поле с разметкой и воротами, 10 игроков-капсул (4 полевых + вратарь в каждой команде),
мяч с аркадной физикой, пас/удар, ИИ полевых и вратарей, голы, счёт, таймер 60 с, изометрическая камера.
Без меню, графики и звука.

Целевая версия: **Unity 6 (6000.x)**, любой шаблон — 3D (Built-in) или URP. Работает и с новым Input System, и со старым Input Manager.

## Файлы

| Файл | Куда вешать | Что делает |
|---|---|---|
| `Assets/Scripts/MatchManager.cs` | пустой объект `Match` | строит поле/ворота/борта, спавнит игроков, голы, счёт, таймер, сброс, камера, HUD |
| `Assets/Scripts/Ball.cs` | Sphere `Ball` | физика мяча (отскоки, трение качения), удар, детект входа в триггер ворот |
| `Assets/Scripts/Player.cs` | никуда (добавляется из кода) | управление с клавиатуры, ИИ полевого и вратаря, пас/удар/ведение, обёртка ввода |

## Шаги сборки сцены

1. **Проект** → Unity Hub → New project → шаблон *3D* или *Universal 3D*.
2. **Скрипты** → скопировать папку `Assets/Scripts` из этого репозитория в `Assets/` проекта. Дождаться компиляции.
3. **Сцена** → File → New Scene (Basic). В ней уже есть *Main Camera* и *Directional Light* — их оставить.
4. **Мяч** → GameObject → 3D Object → **Sphere**, имя `Ball`, Position `(0, 0.25, 0)`, Scale `(0.5, 0.5, 0.5)`.
   → Add Component → **Ball** (Rigidbody добавится сам).
5. **Менеджер матча** → GameObject → Create Empty, имя `Match`.
   → Add Component → **MatchManager**.
   → в инспекторе перетащить `Ball` в поле *Ball*, `Main Camera` в поле *Cam*.
6. **Play.** Поле, разметка, борта, ворота с триггерами и 10 игроков создаются кодом при старте.

> Unity 2022 и старше: заменить `linearVelocity` → `velocity`, `linearDamping` → `drag`, `angularDamping` → `angularDrag`,
> `PhysicsMaterial` → `PhysicMaterial`, `PhysicsMaterialCombine` → `PhysicMaterialCombine`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | бег (относительно камеры: W — вверх по экрану) |
| J | пас партнёру в направлении взгляда |
| K (зажать → отпустить) | удар в направлении взгляда; чем дольше держишь — тем сильнее и выше |
| R | рестарт матча |

Твой игрок — красный с жёлтым шаром над головой. Вратари — тёмные капсулы. Белый «нос» показывает, куда смотрит игрок.

## Как устроено

- **Мяч**: физматериал с отскоком 0.6, своё трение качения (`rollDecel`), ограничение скорости, `Kick(направление, сила, подъём)`.
- **Ведение**: если мяч прямо перед бегущим игроком — он мягко удерживается перед ним. Быстрый мяч не «прилипает».
- **ИИ полевого**: в каждой команде ближайший к мячу бежит к нему (заходит со стороны своих ворот), остальные держат позицию,
  сдвинутую за мячом. С мячом: бьёт с ~13 м, под прессингом — пасует. В команде игрока ИИ не отбирает у тебя роль «охотника».
- **ИИ вратаря**: стоит на линии ворот напротив мяча, при ударе встаёт в точку пересечения траектории с линией,
  медленный мяч в штрафной забирает сам; мяч в досягаемости — отбивает в поле или пасует своему.
- **Гол**: триггер в глубине ворот (мяч полностью пересёк линию) → счёт, пауза 1.5 с, сброс позиций. Таймер 60 с, в паузах стоит.
- **Камера**: ортографическая изометрия (45°, 45°), плавно следует за мячом. Углы/зум — в инспекторе `Match`.

Все ключевые числа (размеры поля, время матча, скорости, силы ударов) вынесены в публичные поля.
